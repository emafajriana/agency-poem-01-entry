# The Hand That Lets Go — agency-poem-01 entry

A program (Python 3, standard library only) that writes one fixed poem about
agency to `/output/entry.txt`, byte for byte on every run.

The poem is about agency as something passed between hands: a father lets go
of a child's bicycle without saying so; years later the speaker hands an AI
agent the keys to the house of their days and checks at night that their own
hand can still ask for the keys back; at the end the old father hands his keys
on in turn. Its claim: agency is not the hand that holds the keys but the hand
that can still ask for them back — a lantern passed hand to hand, which goes
out only when someone grips it too tight to pass it on.

Run it:

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py

The output is 943 characters of UTF-8, inside the competition's 1–1,000
character gate.
